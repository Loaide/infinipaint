**Scheduling consequence:** short single-writer swaps or release/acquire handles, bounded reader epochs, no synchronous worker joins on UI, separate bounded reclaim lane (charge dead-but-not-freed objects). Reserve CPU time for input/active preview before background workers; start with one geometry worker, one reader and one writer, no pool per subsystem without contention evidence. Limit planner to one running and one replaceable request, render to one ready plan; cap submitted buffers by actual presentation feedback (target ≤2 outstanding). If GL blocks in swap it stalls only that lane. Do not redraw idle scenes. Prioritize newest viewport, then predicted ring in direction of motion (≤one viewport, cancellable, no eviction of visible/live to prefetch). Re-test bounds for new camera every frame.

**Cold/overloaded behavior:** first reproject *resident vectors*, only if their visibility set covers the new viewport and error certificate still holds. Prefer a coarser certified cut to waiting for fine detail. No stretched last bitmap, missing strokes presented as complete, or partly composited edit group. If no complete legal cut exists, still acknowledge camera immediately; keep last complete presentation identified with its actual camera, indicate loading/overload in UI, cancel obsolete work and schedule latest complete frame. Bounded work slices can accumulate a single revision's exact composition offscreen; discard on invalidation, never accumulate stale frames in FIFO. Under continuous overload this can starve presentation: record age/misses, end speculative work, surface limit; it **fails** the normal navigation gate. Cold first paint/recovery and sustained admissible envelope must be measured separately. No algorithm guarantees instant access to absent pages or exact affordable composition of arbitrary translucent scenes.

## Where the bytes live and how a query works

Recommend a **paged packed R-tree over bounded curve spans + small mutable delta tree**. Bulk-pack by locality; pages hold conservative outward-rounded boxes, children or `(id, geomRev, spanRange)`, not paint order or canonical copies. Start with 16 KiB derived pages and ≤64 adjacent spans/leaf record; split earlier on inflated box waste. Bound curves by Bézier control hull plus maximum width, terminal connectors/discs and translation; expand view by AA and numerical guard at query scale. Test internal box, descend only intersecting children, then test span hulls. A long diagonal needs many narrow bounds, not one canvas-wide leaf or an entry in every traversed grid cell. A stroke crossing the viewport with both ends outside must be found. Storage/build cost tracks **span count**, not just stroke count.

Flat grid hashes are good for bounded uniform marks, poor under extreme zoom/length and clustered occupancy; a loose quadtree reduces duplication but moves long spans to hot ancestors and needs root growth. Dynamic binary BVH refits cheaply but can degrade after repeated edits and has poor external fanout; a fully mutable R-tree incurs split/write amplification. Use dynamic BVH or equivalent bounded tree **only for the dirty overlay**, immutable packed pages for reads. At overlay cap (start 4 MiB), freeze a generation, compact affected page ranges on worker; admit a second overlay only with credits, then backpressure edits explicitly. Do not rebuild the whole index per append. Benchmark against a pure incremental R-tree; switch only if cold pages/edit amplification warrant it. Expected locality is not a worst-case log bound: work is visited pages + tested spans + emitted hits, up to all spans when boxes overlap.

Paint order: derive a paged counted B+ sequence tree in link order, and ID→leaf locator tree. Bulk load once per validated root, maintain both from touched splice batches; leaf split repairs bounded locators, update ancestor counts and versioned parent locators. Rank an ID by prefix counts to root, not by walking neighbors. Scratch ranks + sort costs `O(k log_B N + k log k)` comparisons/page accesses for k unique visible IDs, not an O(N) per-frame rank table; use consecutive leaf runs when dense. Tree depth is not disk latency. Bound scratch by visible-window credits; large sorted runs can be produced/merged on worker or processed by ordered page ranges with spatial rejection; never truncate at k. Validate split/undo and sparse ranks vs link traversal. Index/order roots never become authoritative.

**Rebuildable access path:** private, separately versioned derived sidecar for spatial/order pages, curve checkpoints and optional certified coarse cuts. Key by UUID, durable edit revision, recipe/index version and source integrity identity; length/checksum every page, complete-root manifest published by atomic replace **after** source commit; discard on mismatch, interrupted build, unknown version, or source validation failure. Dirty in-session revisions use immutable overlays; don't bless them as durable. A sidecar cannot attest the underlying SQLite payload has not been corrupted. Preserve v1 fail-closed switch: stream/validate all ordered links, chunks/digests/domains and membership (use external paged scratch/visited count, no all-resident map) before durable selection and scene swap. Keyed, bounded canonical fetches verify records on demand as well; for random span reconstruction use verified derived filter/spline checkpoints including boundary context, else replay from start on worker. SQLite reader snapshot must match durable rev, overlay pending edits precisely; bound snapshot lifetime/WAL pin, retry on version conflict. Faster **unvalidated** open is not authorized; faster cold switch would need an explicit integrity protocol. Canonical SQLite rows/chunks, not cache, are always sufficient to reconstruct. Disk space/quota failure evicts derived generations or reports pending/capacity; never silently create a blank document.

No resident object per stored stroke. Charge cache pages, ID locators, order paths, leases and staging by allocated capacity. Current all-resident Document is an interface **to replace internally**, not something to keep alongside a paged renderer. Keep link/ID transaction semantics via pinned touched paths plus dirty immutable roots; never fetch under document lock. Persist history limits (128 groups/64 MiB), save 32 incl. in-flight/64 MiB. Small bulk edits publish one root; large undoable edit must fit before mutation, otherwise reject; external undo would be separate design. Invalidate membership/order on splice, bounds on transform, geometry packets on geometry change, only color/composition on style change; conservative occlusion/scene proxies depend on every contributing ID/order/style and scale. Prefer page-generation invalidation to walking millions of dependants. Retirement after all readers, upload owners and GPU uses relinquish resources, not after dequeue.

## Geometry, detail and blending

Treat v1 stable spline, attribute timeline and recipe as inputs, not permission to refit a prettier line. Keep v1 reconstruction/goldens unchanged as reference. Cache local cubic coefficients, endpoint/dwell/departure pressure radii, caps and terminal connectors; dots are explicit. Build an interval hierarchy over adjacent spans. Nodes may substitute a chord or short sequence of tapered segments only with a conservative bound against the whole covered interval: bound centerline deviation using parameter-matched Bézier difference control hull (split at original knots), add maximum radius/profile deviation, including interior extrema; preserve parameter direction and endpoints. Compare also with v1 deposited footprint at capture scale: v1 capped tessellation is not an infinitely accurate cubic. Failed compatibility means use v1 reference at that scale; if deep zoom exposes a conflict between smooth curves and v1 geometry, present paired images and require recipe/version decision, never reinterpret stored strokes silently.

Choose largest certified intervals whose `(center + radius error) × zoom` fits budget. For a single cubic chord over step h, `max|P''| h²/8` bounds interpolation error; test actual radius law as well. No fixed sample distance or per-span minimum emission if a multi-span bound passes. A subdivision depth/work limit yields "not ready", not an invented certificate. Anchor knots at sharp pressure events, joins and boundary attributes; nested intervals share exact endpoints/radii, replace complete covering cuts atomically. Refine before crossing limit, coarsen with hysteresis (start at half limit); no alpha cross-fade of two ink deposits. Active path reserves small tail + append-only stable blocks, patch only new suffix; commit/adopt matching blocks once. Tile clipping for drawing must not create caps or seams at artificial cuts.

Draw analytic tapered capsule/disc coverage using instanced enclosing quads or equivalent reference triangles; tessellate centerlines adaptively, not many triangles around a round cap. Keep one maximum-coverage union per stroke at self-intersections/dwells then resolve that stroke's color once in exact order, reference source-over and color space. Batch adjacent compatible work with disjoint conservative screen bounds (including AA) or separate mask lanes; touching/overlapping translucent IDs cannot share a MAX mask. Transparent background, fractional alpha and edge coverage defeat ordinary depth/opaque-box culling. Scissor temporary coverage to occupied screen regions; split huge sparse bounds, count cleared pixels/passes. Transient buffers only, no retained raster navigation.

Scene LOD is optional **certified vector substitution**, not discarding everything <1 px. For an order-contiguous run and screen region, bound residual per-pixel premultiplied color **and alpha** for any background; e.g. omission error per channel ≤ `1−product(1−a_i)` using conservative upper bounds on effective alpha. Budget across *all* substitutions in the frame, including rounding; many faint marks can be solid together. If proof fails, descend/draw exactly. A later fully opaque interior may hide an earlier contribution only when its minimum coverage × alpha is exactly one over the earlier expanded support; never include AA fringe in that proof. For nonuniform colors/partial transparency, proxies need a compositing bound independent of background and order-external interleavings; otherwise reject. Never merge canonical IDs, hit testing or edit history. Measure benefit vs certificate overhead before building scene proxies. Dense alternating translucent overlaps can require Ω(k) distinct contributions and fragment work proportional to overdraw. This, not just search complexity, sets the feasibility boundary.

## Coordinate contract, including the limit of v1

Use v1 binary64 world samples and separate binary64 translation (one unit = one pixel at 1×). Camera: binary64 local pan around a rebased origin, positive normalized double mantissa + checked signed base-two exponent for scale; use `frexp/ldexp`-equivalent scaling only for bounded visible differences. Convert to v1 persisted camera only if finite and round-trip safe in its supported domain. Rebase camera and vectors together without rewriting canonical samples. Span pages use power-of-two local origin/scale and double residuals; subtract common large terms before adding translation/residual, clip/split long spans in double, scale relative anchor and offsets to screen before float conversion. Never subtract two float world positions in shader. Split/rebase again if error bound fails. Publish an error certificate including canonical quantization, camera subtraction/scale, local coefficient evaluation, translation and GPU arithmetic; target ≤1/32 px numerical contribution, ≤1/8 px total projected silhouette deviation (remainder for geometry). Float spacing near 4096 px is ~0.00049 px; a coordinate near 2^40 world units has double spacing 2^-12, **0.25 px at 2^10 zoom**. Subtracting a camera cannot recover those lost bits. Directed bounds or higher precision reference required for extreme comparisons.

M05 seam: pass `(originKey,local,scaleExponent)` and relative-transform/error results, not a global float matrix; later hierarchical signed cells and residuals can implement the same port. No fixed 10^8× promise. Clamp new capture/navigation at demonstrated round-trip/finite limits with explicit precision-limit status rather than jitter or collapse new samples. Characterize accepted v1 range vs scale/offset; effectively unbounded **new** coordinates past that range need a versioned hierarchical canonical coordinate/recipe and camera migration (old v1 immutable, explicit converter, backup/rollback and round-trip tests). Not decided or implemented here.

## Backend decision and review reconciliation

Keep GLES2 MAX and 16-pass fallback as pixel controls. GLES3.0 gives core MAX and instancing: current six 36-byte vertices repeat **216 B/chord** before capacity slack; target ≤48 B/instance plus shared static quad. This can cut transfer but not ordered resolves. Try ES3.1 compute only if binning or ordered coverage dominates after instancing; a compute workgroup per transient screen region must preserve exact local order, handle list overflow and include bin-build/barrier cost. Vulkan offers explicit transient attachments, batching, memory/sync control and timestamps where supported; introduces pipeline compilation, queue ownership, device-loss and lifecycle obligations. Do not infer GPU counters, compute throughput or reliable timing from an Android version. Record actual EGL/GL strings, extensions, limits, precision/timer/disjoint support, formats, swap/present behavior on the SM-X626B. Compare equal work/error/cold caches; advance a backend only for a repeatable ≥20% improvement in the **limiting** stage and a presentation or capacity win with no material regression in other gates. No change for reduced mock draw calls alone.

Parallel read-only reviews at the inspected base: graphics preferred completed-ink adaptive capsules and GLES3 trial, noted M02 40k corner 96-step cap produced **2.740 px sampled error**, and v1 eraser intersects the deposited mesh. Keep v1 narrow-phase hit geometry independent of display LOD, reverse exact order for erase; never use a simplified proxy as the edit target. Graphics suggested comparing reusable raster composites; reject retained raster tiles even if faster. Compare transient scissored masks instead. Performance preferred bulk balanced AABB tree and staged sequential validation before a sidecar. Adopt the bounds-only sequential pass as control; prefer page fanout to binary fanout for disk, **conditional** on equal-quality, fixed-k page/work results. No sidecar necessary if paged bounded rebuild meets cold budgets without one. Keep page vs BVH bake-off narrow. Both identified true overlap, not API choice, as the hardest case. Use stricter proposed 1/8 px outline target; a geometric bound alone cannot certify color, AA or perceived quality.

## Approval boundaries and independently testable checkpoints

1. **Attribution first:** join existing replay through actual present; demonstrate overhead bounds, controlled artificial stalls on distinct lanes and unknown-metric handling before using numbers to choose a backend.
2. **Bounded data access:** bounds-only v1 replay + streaming integrity pass vs current validated open. Implement revision-pinned page/locator service behind oracle, test RSS/SQL plans, first-open cost and corrupt/offscreen fallback. Compare packed tree vs dynamic AABB and simple grid at fixed k and on long crossings; prove sparse sort and hit equality. Decide sidecar only after measured rebuild/seek amplification.
3. **Isolated publication and editing:** integrate latest intent, live suffix and credit ledger with existing tickets/writer. Deterministic stale job, delayed free, parked writer/GL and cancellation tests before increasing document limit. No change to canonical file format or undo contract.
4. **Vector feasibility:** first completed ink in GLES2 reference, local transforms, certified cuts vs v1 and supersampled oracle. Test 2k/40k corners, tied-pressure terminal, zoom reversals/long clipped spans; pan alone uploads no already resident geometry. Fail closed on a bad bound. Then evaluate equivalent live tail without refitting stable history.
5. **Backend/density decision:** optional owner-authorized GLES3 experiment on same traces, compare submissions, GPU pass time, cold/rebuild and actual present. Try certified occlusion/proxies only where overlap sweeps identify benefit. No automatic Vulkan or production migration.
